# ItaPets - E-commerce de Produtos Pet

Projeto desenvolvido para a disciplina de **Tecnologias de Desenvolvimento para Internet** do curso de Sistemas de Informação (UFS).

## 🚀 Sobre o Projeto
O **ItaPets** é uma aplicação web desenvolvida para a comercialização de produtos pet. O projeto está sendo construído de forma **progressiva**, partindo da estruturação em **HTML5** e evoluindo com a estilização via **CSS3** e a adição de interatividade com **JavaScript**, seguindo as melhores práticas de semântica, acessibilidade e SEO.

## 🛠️ Tecnologias e Funcionalidades
- **HTML5:** Estruturação semântica e acessível das páginas.
- **CSS3:** Estilização, layout responsivo e identidade visual (em desenvolvimento progressivo).
- **JavaScript:** Manipulação do DOM e interatividade do usuário (em desenvolvimento progressivo).
- Listagem dos 20 produtos principais na página inicial.
- Páginas de detalhes individuais para cada produto.
- Formulário de contato/feedback funcional.

## 📁 Estrutura de Arquivos
- `index.html`: Página inicial com catálogo de produtos.
- `contato.html`: Formulário de envio de mensagens e suporte.
- `produtos/`: Páginas de detalhes individuais de cada item.
- `css/`: Arquivos de estilo para layout e design.
- `js/`: Scripts para lógica e interatividade.
- `img/`: Repositório de imagens e mídias do site.
