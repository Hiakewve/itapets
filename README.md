# ItaPets - E-commerce de Produtos Pet

Projeto desenvolvido para a disciplina de **Tecnologias de Desenvolvimento para Internet** do curso de Sistemas de Informação (UFS).

## 🚀 Sobre o Projeto
O **ItaPets** é um site estático desenvolvido exclusivamente em **HTML5**, seguindo as melhores práticas de semântica, acessibilidade e SEO.

## 🛠️ Funcionalidades
- Listagem dos 12 produtos principais na página inicial.
- Páginas de detalhes individuais para cada produto.
- Formulário de contato/feedback integrado via envio de e-mail.

## 📁 Estrutura de Arquivos
- `index.html`: Página inicial com catálogo.
- `contato.html`: Formulário de envio de mensagens.
- `produtos/`: Páginas detalhadas de cada item.
- `img/`: Diretório de imagens do site.
